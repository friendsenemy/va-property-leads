# Virginia FOIA requests (free data the counties do not publish)

The Virginia Freedom of Information Act (Va. Code § 2.2-3700 et seq.) gives **citizens of
the Commonwealth** and Virginia media a right to public records (§ 2.2-3704(A)). A Maryland
resident has no statutory right to a response, so these letters should go out **from a
Virginia resident or a Virginia-registered business** (your partner, a Virginia LLC, or a
Virginia-licensed agent). The public body must respond within **5 working days** of
receipt (§ 2.2-3704(B)); it may take 7 more working days if it says so in writing. It may
charge reasonable actual costs (§ 2.2-3704(F)); ask for an estimate first. Records must be
provided in the electronic form they are kept in when asked (§ 2.2-3704(G)).

What was checked, and what is missing (October 2026):

| County | Code enforcement cases | Published? |
|---|---|---|

| Fauquier | Community Development, Civic Access portal | The portal has a Code Case search, but it returns nothing for any date range: no public code case types are configured |
| Town of Warrenton | Community Development | OpenGov permit portal; no code-enforcement record type; list search needs a token; robots bars automation |
| Town of Colonial Beach | Planning & Community Development | Complaint forms only |

Each letter asks for the same thing: an electronic export of the case list the county keeps.
Fill in the sender block and the date; nothing else.

## 1. King George County: code compliance case list

**To:** King George County, Department of Community Development, Building & Code Compliance
**Address:** 10459 Courthouse Drive, Suite 104, King George, VA 22485
**Email:** the FOIA officer listed at kinggeorgecountyva.gov (County Administration)
**Subject:** Virginia FOIA request: code compliance and unsafe-structure case list (electronic)

> Dear FOIA Officer,
>
> Under the Virginia Freedom of Information Act, Va. Code § 2.2-3700 et seq., I request an
> electronic copy of the County's code compliance / property maintenance case records for
> cases opened from January 1, 2020 to the present, including for each case: case or
> complaint number, case type or violation category, property address, tax map or parcel
> number, date opened, current status, date closed (if closed), and whether the case
> involves an unsafe structure, a derelict structure under § 15.2-907.1, a spot blight
> determination under § 36-49.1:1, a condemnation, or a demolition order. I also request
> the list of demolition permits issued since January 1, 2020 (permit number, address,
> parcel, date) and any list of derelict or blighted structures the County maintains.
>
> I ask for the records in the electronic form in which they are kept (CSV, Excel or a
> database export), as § 2.2-3704(G) provides, not paper copies. I do not need inspector
> notes, photographs or complainant information; please withhold complainant identities
> rather than treat them as a reason to deny the request. If any part is withheld, please
> cite the specific exemption and release the rest, as § 2.2-3704(B) requires.
>
> If the cost of producing these records will exceed $50, please send an estimate before
> doing the work (§ 2.2-3704(F)). I am a citizen of the Commonwealth. Please send the
> records to the email below.
>
> Thank you,
> [Name], [Virginia address], [email]

## When a response arrives

Save the export as `data/distress/manual.csv` rows (`county,kind,date,address,zip,parcel,
case_number,status,source,url,detail`), one per case, or send the file over and it will be
converted. The next daily run matches every row to its parcel.
